# agentic/ — Pontifex operational surface

Operational collaboration surface for the **Pontifex** persona (consumption / MCP-serving layer), mirroring the programme's agentic framework.

- `briefs/` — immutable context documents (dated `YYYY-MM-DD-topic.md`)
- `decisions/` — versioned local decisions (`NNNN-title-kebab.md`)
- `em-curso/` — current active work
- `planeado/` — queued work intent
- `done/` — closing notes (the memory of finished work)
- `roadmap.md` — horizons
- `ROLE.md` — operational expansion of the persona (read with `../AGENTS.md`)

Read `AGENTS.md` (repo root) first; this surface is operational expansion, not a substitute. Cross-persona items mirror to `/Volumes/G-DRIVE/Shared/sbd-ai-runtime/handover/em-curso/` per AGENTS.md §0.5.
